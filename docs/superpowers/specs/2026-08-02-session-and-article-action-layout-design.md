# 会话与文章操作布局设计

## 目标

修复代码分析工作台左侧栏的高度分配错误，并明确区分会话级与文章级操作：会话操作针对整个会话，文章操作仅针对对应文章。

## 布局

左侧栏使用四个明确的网格区域：目录选择按钮、项目树、最近会话、语言选择。项目树和最近会话都必须拥有受限高度与各自的纵向滚动；语言选择位于最后一个 `auto` 行，不参与剩余高度分配。展开项目目录不得挤压最近会话或语言选择。

## 会话级操作

每个会话行保留单个三点菜单，避免在窄侧栏挤压标题。菜单项目是：

- 重命名；
- 归档或恢复；
- 从会话当前激活文章创建独立会话分支；
- 导出整个会话；
- 删除。

删除菜单项与其他项目使用相同的颜色、字号和无图标样式。永久删除的危险强调仅出现在确认对话框。

会话级分支和导出必须在后端以 `sessionId` 为输入：分支使用会话的 `activeDocumentId` 作为复制起点；导出包含会话元数据、分支与所有文章，而非只导出当前文章。

## 文章级操作

每篇已完成的助手文章底部显示操作条，依次提供复制、回退、从该文章创建分支、导出该文章。操作条必须是文章容器的底部内容或纵向消息行的第二行，不能作为横向 Flex 消息行的同级右侧元素。文章级导出维持现有 Markdown/JSON 两种格式。

## 错误与可用性

- 已归档会话的可改变状态操作保持禁用；查看和导出仍可用。
- 会话没有 `activeDocumentId` 时，会话级分支禁用。
- 所有新增菜单操作具备可访问名称、标题提示、键盘菜单语义与禁用状态。
- 失败通过既有状态消息显示，且不得清空当前会话或文章。

## 测试

增加单元测试验证：侧栏网格的四区结构、菜单项目及删除项的统一结构；会话分支以活动文章为起点；会话导出包含全部文章；文章操作条在助手文章容器内。通过渲染树与行为测试覆盖 UI，通过服务测试覆盖会话导出与分支语义。

## 非目标

- 不修改现有文章级 Markdown/JSON 导出格式。
- 不在侧栏会话行直接堆叠多个操作图标。
- 不改动批注、工具调用或输入框功能。
